# ⌨️ Typing Speed Test Game

A fun web-based project built with **HTML, CSS, and JavaScript** to test and improve your typing speed.  
The game measures how fast and accurately you can type a given sentence.

## ✨ Features
- Random sentence generator for typing practice.
- Calculates typing speed in **Words Per Minute (WPM)**.
- Measures typing accuracy by comparing input with the original text.
- Clean and responsive design using HTML & CSS.
